# MVP-01

Primer modelo de app de finanzas personales.

## ¿cómo ejecutar?

1. Descarga o clona este repositorio en tu equipo.
2. Abre el archivo `index.html` en tu navegador (puedes hacer doble clic desde el explorador de archivos o elegir *Open with Live Server* si usas VS Code).
   - Si prefieres usar la terminal, ejecuta `python -m http.server 8000` (o `py -m http.server 8000` en Windows) dentro de la carpeta del proyecto y navega a `http://localhost:8000/index.html`.
3. Verás la pantalla de inicio de sesión. Si lo prefieres, presiona **Usar demo** para rellenar automáticamente las credenciales `admin` / `1234` y acceder al panel.
4. Carga movimientos, ajusta categorías desde la pestaña de configuración y consulta la visualización mensual.
